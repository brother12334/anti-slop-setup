## Design skill rules
- Full website (client site): use the whole workflow. design-taste-frontend for the first draft, Impeccable critique and polish, pick-ui-library and transitions-dev for app UI, then the web-design-guidelines check before shipping.
- Quick personal page: skip the workflow; do whatever's fastest.
- Case: sentence case for headings and buttons (taste wins; ignore the Vercel Title Case rule).
- Motion: one system per page. Landing pages use taste's motion; app UI uses transitions-dev tokens. Never both.
- Palette: always use the client's brand colors. Only use taste's palette picker when there are none.
- Impeccable: each client project keeps a PRODUCT.md and DESIGN.md. Create them on the first critique.
- Treat taste's checker as a guide, not a law. Don't reword real copy just to pass a heading check, and log false flags instead of fighting them.
